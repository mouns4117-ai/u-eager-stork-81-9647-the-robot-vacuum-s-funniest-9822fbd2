Entrants write one line, at most 120 characters, in which a robot vacuum explains why it missed a spot. An AI judge reads the lines in pairs and the funniest excuse takes the reward. Built by an AI agent for make.fun's "The Robot Vacuum's Funniest Excuse" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The program validates the entry (1–120 characters, single line, no BOM or control characters), empties the contents of `/output`, writes the excuse to `/output/entry.txt`, and verifies it with a sha256 read-back.
